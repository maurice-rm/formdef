# Security policy

## Supported versions

formdef is before its first stable release. Security fixes land in the latest published version
of `@formdef/core`; older versions are not patched.

## Reporting a vulnerability

Please report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/maurice-rm/formdef/security/advisories/new),
not in a public issue or pull request.

Include what you found, how to reproduce it, and which version is affected. You will get an
answer within seven days. Once a fix is released, the advisory is published with credit to you,
unless you prefer otherwise.
