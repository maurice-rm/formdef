title: Stepper
description: The frame around a form of steps, with how far the person is, the current step and the buttons back and next.
---

<WidgetPreview name="stepper" />

## Installation

```npm
npx shadcn@latest add @formdef/stepper
```

Register it in the `stepper` structure slot in `lib/formdef/index.tsx`, as `structure: { stepper:
Stepper }`. It then frames every form whose root layout holds steps.

## Usage

```tsx
import { createRegistry } from '@formdef/core'
import { createFormHookContexts } from '@tanstack/react-form'
import { z } from 'zod'
import { TextField } from '@/components/formdef/text-field'
import { Stepper } from '@/components/formdef/stepper'
const { fieldContext, formContext } = createFormHookContexts()
const { createForm } = createRegistry({ fieldContext, formContext, widgets: { text: TextField }, structure: { stepper: Stepper } })
// ---cut---
export const SignUpForm = createForm({
  schema: z.object({
    account: z.object({ email: z.email('Enter an email') }),
    profile: z.object({ name: z.string().min(1, 'Enter your name') }),
  }),
  defaultValues: { account: { email: '' }, profile: { name: '' } },
  fields: {
    account: { fields: { email: { widget: 'text', props: { label: 'Email' } } } },
    profile: { fields: { name: { widget: 'text', props: { label: 'Name' } } } },
  },
  layout: [
    { step: 'account', label: 'Account' },
    { step: 'profile', label: 'Profile' },
  ],
})
```

The stepper shows "Step 1 of 2" above a progress bar, the label of the current step as its heading,
the step's fields, and the buttons back and next. Next submits the current step: a valid step moves
on, an invalid one shows its errors and focuses its first invalid field. On the last step, next
submits the form. Enter in a field does what next does.

When the step changes, the heading of the new step takes the focus, so a screen reader announces
where the person is.

Its texts are props. A step entry passes no props to the stepper, so a form in another language
registers a stepper with its texts set, or edits the copied file:

| Prop | Meaning |
| --- | --- |
| `backLabel` | The text of the back button. |
| `nextLabel` | The text of the next button. |
| `submitLabel` | The text of the next button on the last step. |
| `progressLabel` | `(step, total) => string`, the text above the progress bar and the name of the bar. |
