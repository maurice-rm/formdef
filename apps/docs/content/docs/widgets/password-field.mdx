## Installation

```npm
npx shadcn@latest add @formdef/password-field
```

Register it under `widgets` in `lib/formdef/index.tsx`, as `widgets: { password: PasswordField }`.
The widget serves `string` values.

## Usage

```tsx
import { createRegistry } from '@formdef/core'
import { createFormHookContexts } from '@tanstack/react-form'
import { z } from 'zod'
import { PasswordField } from '@/components/formdef/password-field'
const { fieldContext, formContext } = createFormHookContexts()
const { createForm } = createRegistry({ fieldContext, formContext, widgets: { password: PasswordField } })
// ---cut---
export const SignInForm = createForm({
  schema: z.object({ password: z.string().min(1, 'Enter your password') }),
  defaultValues: { password: '' },
  fields: {
    password: {
      widget: 'password',
      props: {
        label: 'Password',
        autoComplete: 'current-password',
        labelAside: <a href="/reset-password">Forgot password?</a>,
        reveal: { show: 'Passwort anzeigen', hide: 'Passwort verbergen' },
      },
    },
  },
})
```

The button beside the input shows the password as plain text and hides it again. Its accessible
name is `Show password` or `Hide password`; `reveal` renames both, for instance into the language of
your form.

Set `autoComplete` to `current-password` on a sign-in form and to `new-password` where someone
chooses one, so a password manager knows whether to fill in or to suggest.
