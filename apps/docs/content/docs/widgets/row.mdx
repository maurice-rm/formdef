## Installation

```npm
npx shadcn@latest add @formdef/row
```

Register it in the `row` structure slot in `lib/formdef/index.tsx`, as `structure: { row: Row }`.
From then on every `{ row }` entry of a layout renders through it.

## Usage

```tsx
import { createRegistry } from '@formdef/core'
import { createFormHookContexts } from '@tanstack/react-form'
import { z } from 'zod'
import { TextField } from '@/components/formdef/text-field'
import { Row } from '@/components/formdef/row'
const { fieldContext, formContext } = createFormHookContexts()
const { createForm } = createRegistry({ fieldContext, formContext, widgets: { text: TextField }, structure: { row: Row } })
// ---cut---
export const NameForm = createForm({
  schema: z.object({ firstName: z.string(), lastName: z.string() }),
  defaultValues: { firstName: '', lastName: '' },
  fields: {
    firstName: { widget: 'text', props: { label: 'First name' } },
    lastName: { widget: 'text', props: { label: 'Last name' } },
  },
  layout: [{ row: ['firstName', 'lastName'] }],
})
```

The row is a container query, not a breakpoint: it places its fields side by side once its own
width reaches Tailwind's `md` container size, and stacks them below that. A row in a narrow sidebar
stacks even on a wide screen.

The fields share the width equally. A `className` passed through the entry's `props` goes on the
row's flex container.
