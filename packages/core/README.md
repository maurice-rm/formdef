# @formdef/core

Describe a form once as a typed object, render it as a React component — with the compiler
checking that every widget fits the value it receives.

Built on [TanStack Form](https://tanstack.com/form). Not released yet; see the
[repository](https://github.com/maurice-rm/formdef) for the current state.

## Requirements

- React 19
- `@tanstack/react-form` `>=1.33.5 <1.34.0`
- TypeScript 5.4 or later
- Node 22 or later
